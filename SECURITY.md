# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please report it privately: on GitHub, open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue.

Include what you found, how to reproduce it, and what it affects. Leave out your own server address, username and password. You can expect a first reply within a week.

Examples of what counts: credentials leaking into logs, files or crash output; a provider response that runs code or reads local files; anything that weakens how passwords are kept in Windows Credential Manager.
